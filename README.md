# Moksha-Pro

Luxury website build for **Moksha Himalaya Spa Resort** (Timber Trail Resorts, Parwanoo, Himachal Pradesh).

## Overview
- Complete multi-page luxury resort experience (Home, Suites, Dining, Wellness, Experiences, Weddings & Events, Gallery, Packages, Careers, Blog, Contact, Legal).
- Responsive bespoke design with custom typography (Cormorant Garamond + Jost).
- Interactive animations with GSAP, ScrollTrigger, Lenis smooth scrolling.
- Resort switcher, sticky editorial layouts, full-screen heroes, interactive booking modal, and filtering galleries.

## Development
- Local Preview: `node tools/serve.mjs 4173`
- Rebuild Static Pages: `node build.mjs`
- Link & Asset Verification: `node tools/check-links.mjs`
